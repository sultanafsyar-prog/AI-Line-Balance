# IE 產線平衡系統－使用指南

## 1. 開始使用

1. 使用支援的瀏覽器開啟正式系統網址。
2. 使用 IT 或 IE 管理員提供的公司帳號登入。
3. 使用語言切換器選擇英文、印尼文或繁體中文。
4. 側邊選單只會顯示目前角色可使用的功能。

請勿共用密碼或使用他人帳號。若帳號、廠房或產線權限不正確，請聯絡 IT 管理員。

## 2. 角色快速說明

| 角色 | 常用工作 |
|---|---|
| IE 管理員 | 管理型體、標準、產線配置、使用者、監控、歷史與報表 |
| IE 操作員 | 維護 IE 標準並檢視生產明細 |
| 線長 | 輸入每小時生產資料並結束指定產線的班次 |
| 管理層 | 檢視儀表板、監控、分析與報表 |
| IT 管理員 | 管理使用者與技術權限 |
| PPIC | 維護或檢視生產目標與計畫資料 |

## 3. 型體資料庫

### 手動建立型體

1. 開啟 **型體資料庫（Model Library）**。
2. 選擇 **手動建立（Create manually）**。
3. 輸入型體名稱、文章、階段、產線類型及目標資料。
4. 新增所需工段。
5. 針對每個工段輸入標準人力、節拍時間、每小時目標及工序。
6. 檢查系統對缺少或異常人力數值的提示。
7. 儲存型體。

### 匯入 NB Standard

1. 開啟 **型體資料庫**。
2. 如有需要，先下載系統提供的 Excel 範本。
3. 選擇 **上傳 NB Standard**，並選取 Excel 檔案。
4. 檢查系統解析出的型體、工段與工序。
5. 修正不完整或解析錯誤的資料。
6. 確認完成後再儲存。

### 編輯型體

1. 在型體資料庫選擇型體。
2. 開啟 **編輯型體（Edit Model）**。
3. 更新基本資料、標準、工段或工序。
4. 儲存變更。

歷史生產資料會保留原工段關聯。若只是修正拼字，請勿另外建立重複型體。

### 上傳型體圖片

1. 開啟型體編輯或圖片操作功能。
2. 選擇允許大小內的 JPG、PNG 或 WebP 圖片。
3. 上傳並確認圖片已顯示。

圖片更新成功後，監控／TV 的標準快取會自動更新。

## 4. 將型體配置至產線

1. 開啟產線或配置管理畫面。
2. 選擇廠房與產線。
3. 加入目前排程生產的型體。
4. 若同一時段會生產多個款式，可保留多個有效型體。
5. 只有在型體不再適用時，才移除或停用配置。

實際生產輸入只能使用該產線目前有效型體所屬的工段。

## 5. 輸入實際生產資料

1. 開啟 **實際輸入（Input Actual）** 或線長頁面。
2. 選擇已被授權的產線。
3. 選擇目前生產的型體／款式。
4. 選擇生產工段。
5. 選擇 **第一班** 或 **第二班**。
6. 選擇 **正常**、**加班 1 小時**、**加班 2 小時**或**加班 3 小時**。
7. 選擇生產時段。
8. 輸入：
   - 產量。
   - 實際到位人力。
   - 停機分鐘。
   - 發生停機時的停機原因。
   - 不良數量。
9. 確認資料後選擇 **儲存**。

同一產線、工段、日期與時段再次儲存時，系統會更新原有資料。覆寫已存在的時段資料前，系統會要求確認。

### 第一班時間

- 一般：07:30–16:30。
- 休息：12:30–13:30。
- 星期五：07:30–17:00，休息 11:30–13:00。
- 正常下班後可增加 1 至 3 小時加班。

### 第二班時間

- 一般：20:30–隔日 05:30。
- 預設休息：00:30–01:30。
- 05:30 後可增加 1 至 3 小時加班。
- 午夜後資料仍歸屬於第二班開始當日。

## 6. 半天或部分班次輸入

系統支援部分班次輸入。

範例：只生產 07:30 至 12:30。

1. 輸入每一個實際有生產的時段。
2. 未使用的時段保持空白；除非「零產量」具有實際營運意義，否則不要建立不實的零產量資料。
3. 該班生產確定結束後，選擇 **結束班次**。

重要：結班會鎖定整個所選班次。之後無法透過一般輸入補登剩餘時段。如需修正，請聯絡已授權的管理員。

## 7. 結束班次

1. 確認畫面顯示正確的產線與班次。
2. 檢查所有已取得的生產輸入。
3. 選擇 **結束班次（Close Shift）**。
4. 若畫面顯示電子郵件欄位，可輸入有效的主管信箱，或保持空白。
5. 確認操作。

系統會：

- 依所選產線、生產日期及班次建立唯一封存。
- 鎖定該班次的實際資料。
- 保持同一日期的另一班仍可操作。
- 僅在封存成功後寄送選填郵件。

若系統提示班次已結束，請先確認產線、生產日期及班次。請勿持續重試，應先檢查 **班次歷史** 或聯絡 IE 管理員。

## 8. 監控與 TV 畫面

使用 **監控（Monitor）** 檢視：

- 有效產線及配置型體。
- 目前產量與目標比較。
- 平均 LLER。
- 尚未輸入資料的產線。
- 低於注意門檻的產線。
- 目前營運警示。

TV 畫面可供生產現場共同查看。如有需要可手動重新整理；標準資料變更後，系統通常會自動使快取失效並更新。

## 9. 班次歷史

1. 開啟 **班次歷史（Shift History）**。
2. 依期間、廠房、產線、班次或日期篩選。
3. 選擇一筆封存資料以開啟每小時明細。

若同一產線曾生產一個或多個型體，封存清單會顯示相關型體／款式。每小時明細包括：

- 生產時間。
- 型體／款式。
- 工段。
- 產量與目標。
- 標準人力、理論人力與實際人力。
- LLER。
- 停機時間與原因。
- 不良數。

如畫面提供 **匯出 Excel**，可下載目前篩選後的歷史資料。

## 10. 分析與日報匯出

使用 **分析（Analytics）** 查看所選期間的績效趨勢。結果只會包含使用者有權限的廠房或產線。

使用 **匯出今日報表** 或日報匯出功能下載產線彙總與每小時明細。分享檔案前請確認選擇的日期正確。

## 11. 問題排除

### 「您沒有此產線的權限」

帳號未被配置至該產線或廠房。請 IE 管理員或 IT 管理員確認權限。

### 「此工段／型體未在產線啟用」

所選工段屬於尚未有效配置至該產線的型體。請修正產線配置，或選擇正確型體。

### 「班次已結束」

所選產線、日期及班次已有封存。請檢查班次歷史；一般輸入無法修改已結束班次。

### 無效的生產時段

請選擇系統畫面提供的時段。休息時間及超出正常工時加最大加班範圍的時間會被拒絕。

### 網路中斷

保持頁面開啟並恢復網路。現場輸入流程可暫存短暫離線提交，但在結班前必須確認重新連線後資料已顯示。

### 登入逾時

請重新登入。尚未儲存的表單內容可能需要重新輸入。

### TV 未顯示最新型體或圖片

先重新整理 TV 畫面一次。若仍顯示舊資料，請將型體名稱與產線回報 IT。

## 12. 條碼與 MES 現況

目前版本尚未啟用 MES 條碼掃描。請勿使用個人帳號或系統管理員帳號直接連接 MES 生產資料庫。

未來整合應依下列順序進行：

1. MES／IT 說明條碼內容與資料權責。
2. MES／IT 提供核准的唯讀 API、View 或整合帳號。
3. 產線平衡系統將條碼對應至型體／款式與生產工單。
4. 在正式使用前，先於測試環境驗證效能與資料正確性。
